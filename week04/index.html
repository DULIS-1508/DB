Week 04 · 집계 함수

개수·합계·평균·최댓값으로 데이터를 요약하기

HOME 실습 가이드 환경·제출 안내 도서관 DB 내려받기

학습 목표

  • COUNT으로 행의 개수를 셀 수 있다.
  • SUM, AVG, MIN, MAX로 값을 요약할 수 있다.
  • WHERE와 집계 함수를 함께 사용할 수 있다.

준비

실습 안내를 참고해 도서관 DB를 불러온 뒤 시작하세요. 표 구조가 기억나지 않으면 실습 가이드의 "우리가 쓸 표 3개"를 참고하세요.

실습 과제

아래 문제를 풉니다. week04/answer.sql 파일에 문제 번호와 함께 SQL을 작성하고, 실행 결과를 캡처해 제출하세요.

문제 1

book에 등록된 전체 도서 수를 구하세요. 힌트: COUNT(*)

문제 2

member의 전체 회원 수를 구하세요. 힌트: COUNT(*)

문제 3

모든 도서의 총 소장 부수(total_copies의 합)를 구하세요. 힌트: SUM(total_copies)

문제 4

도서의 가장 오래된 출판연도와 가장 최근 출판연도를 함께 구하세요. 힌트: MIN(pub_year), MAX(pub_year)

문제 5

아직 반납하지 않은 대출은 몇 건인지 구하세요. 힌트: WHERE return_date IS NULL 로 COUNT
