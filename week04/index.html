Week 04 · 데이터 집계

HOME 웹에서 SQL 연습 실습 가이드 환경·제출 안내 도서관 DB 내려받기

학습 목표

  • COUNT으로 개수를 셀 수 있다.
  • SUM·AVG·MIN·MAX를 쓸 수 있다.
  • DISTINCT·IS NULL과 함께 집계할 수 있다.

준비

웹에서 SQL 연습에서 도서관 DB를 골라 바로 실습할 수 있습니다. 표 구조는 실습 가이드를 참고하세요.

실습 과제

아래 문제를 풀어 week04/answer.sql에 문제 번호와 함께 SQL을 작성하고, 실행 결과를 캡처해 제출하세요.

문제 1

전체 도서 수를 구하세요. 힌트: COUNT(*)

문제 2

모든 도서의 총 소장 부수를 구하세요. 힌트: SUM(total_copies)

문제 3

도서의 가장 오래된/최근 출판연도를 함께 구하세요. 힌트: MIN, MAX

문제 4

아직 반납하지 않은 대출 건수를 구하세요. 힌트: WHERE return_date IS NULL

문제 5

도서에 등장하는 출판사의 종류 수(중복 제거)를 구하세요. 힌트: COUNT(DISTINCT publisher)
