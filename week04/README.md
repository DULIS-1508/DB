# Week 04 · 집계 함수
> 개수·합계·평균·최댓값으로 데이터를 요약하기

## 학습 목표
- COUNT으로 행의 개수를 셀 수 있다.
- SUM, AVG, MIN, MAX로 값을 요약할 수 있다.
- WHERE와 집계 함수를 함께 사용할 수 있다.

## 준비
[실습 안내](../guide.html)를 참고해 `db/library_schema.sql`을 불러온 뒤 시작하세요.

## 실습 과제
1. book에 등록된 전체 도서 수를 구하세요. (힌트: COUNT(*))
2. member의 전체 회원 수를 구하세요. (힌트: COUNT(*))
3. 모든 도서의 총 소장 부수(total_copies의 합)를 구하세요. (힌트: SUM(total_copies))
4. 도서의 가장 오래된 출판연도와 가장 최근 출판연도를 함께 구하세요. (힌트: MIN(pub_year), MAX(pub_year))
5. 아직 반납하지 않은 대출은 몇 건인지 구하세요. (힌트: WHERE return_date IS NULL 로 COUNT)

## 제출 방법
1. `answer.sql`에 문제 번호와 함께 SQL을 작성합니다.
2. 실행 결과를 캡처해 `result.png`로 이 폴더에 함께 올립니다.
3. **Commit & Push** 하면 제출 완료입니다.
