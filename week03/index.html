3장 · WHERE로 조건에 맞는 행만 골라내고, 정렬하기

HOME 웹에서 SQL 연습 실습 가이드 환경·제출 안내 도서관 DB 내려받기

학습 목표

  • WHERE와 비교·논리 연산자로 조건을 표현할 수 있다.
  • LIKE·BETWEEN·IN을 사용할 수 있다.
  • ORDER BY로 정렬할 수 있다.

준비

웹에서 SQL 연습에서 도서관 DB를 골라 바로 실습할 수 있습니다. 표 구조는 실습 가이드를 참고하세요.

실습 과제

아래 문제를 풀어 week03/answer.sql에 문제 번호와 함께 SQL을 작성하고, 실행 결과를 캡처해 제출하세요.

문제 1

카테고리가 '컴퓨터'인 도서의 제목과 저자를 조회하세요. 힌트: WHERE category = '컴퓨터'

문제 2

2020년(포함) 이후 출판된 도서를 출판연도 내림차순으로 조회하세요. 힌트: WHERE pub_year >= 2020, ORDER BY ... DESC

문제 3

제목에 '데이터'가 포함된 도서를 조회하세요. 힌트: LIKE '%데이터%'

문제 4

출판연도가 2015~2020인 도서를 오름차순으로 조회하세요. 힌트: BETWEEN 2015 AND 2020

문제 5

카테고리가 '문학' 또는 '역사'인 도서의 제목과 카테고리를 조회하세요. 힌트: IN ('문학','역사')
