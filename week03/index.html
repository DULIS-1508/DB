Week 03 · WHERE 조건과 정렬

조건으로 걸러내고 원하는 순서로 줄 세우기

HOME 실습 가이드 환경·제출 안내 도서관 DB 내려받기

학습 목표

  • WHERE로 조건에 맞는 행만 조회할 수 있다.
  • LIKE, BETWEEN, IN으로 다양한 조건을 표현할 수 있다.
  • ORDER BY로 오름차순/내림차순 정렬할 수 있다.

준비

실습 안내를 참고해 도서관 DB를 불러온 뒤 시작하세요. 표 구조가 기억나지 않으면 실습 가이드의 "우리가 쓸 표 3개"를 참고하세요.

실습 과제

아래 문제를 풉니다. week03/answer.sql 파일에 문제 번호와 함께 SQL을 작성하고, 실행 결과를 캡처해 제출하세요.

문제 1

카테고리가 '컴퓨터'인 도서의 제목과 저자를 조회하세요. 힌트: WHERE category = '컴퓨터'

문제 2

2020년(포함) 이후에 출판된 도서를 출판연도 내림차순으로 조회하세요. 힌트: WHERE pub_year >= 2020, ORDER BY ... DESC

문제 3

제목에 '데이터'가 들어간 도서의 제목을 조회하세요. 힌트: LIKE '%데이터%'

문제 4

출판연도가 2015년부터 2020년 사이인 도서를 출판연도 오름차순으로 조회하세요. 힌트: BETWEEN 2015 AND 2020

문제 5

카테고리가 '문학' 또는 '역사'인 도서의 제목과 카테고리를 조회하세요. 힌트: IN ('문학','역사')
