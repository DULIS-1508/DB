# Week 03 · 3장 데이터 필터링

## 학습 목표
- WHERE와 비교·논리 연산자로 조건을 표현할 수 있다.
- LIKE·BETWEEN·IN을 사용할 수 있다.
- ORDER BY로 정렬할 수 있다.

## 실습 과제

3. 제목에 '데이터'가 포함된 도서를 조회하세요.
4. 출판연도가 2015~2020인 도서를 오름차순으로 조회하세요.
5. 카테고리가 '문학' 또는 '역사'인 도서의 제목과 카테고리를 조회하세요.
