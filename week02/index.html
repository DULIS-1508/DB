Week 02 · 데이터 CRUD (생성·조회·수정·삭제)

2장 · 데이터를 넣고(Create) 꺼내고(Read) 고치고(Update) 지우기(Delete)

HOME 웹에서 SQL 연습 실습 가이드 환경·제출 안내 정답 확인 도서관 DB 내려받기

학습 목표

  • INSERT로 새 데이터를 넣을 수 있다.
  • UPDATE·DELETE로 데이터를 수정·삭제할 수 있다.
  • WHERE로 대상을 정확히 지정할 수 있다.

준비

웹에서 SQL 연습에서 도서관 DB를 골라 바로 실습할 수 있습니다. 표 구조는 실습 가이드를 참고하세요.

연습창에서 데이터를 바꿔도 새로고침하면 되돌아옵니다. 마음껏 실습하세요.

실습 과제

아래 문제를 풀어 week02/answer.sql에 문제 번호와 함께 SQL을 작성하고, 실행 결과를 캡처해 제출하세요.

문제 1

본인을 회원으로 member에 INSERT 하세요. (이름은 자유, 학과·유형·이메일·가입일 포함) 힌트: INSERT INTO member (열목록) VALUES (값)

문제 2

방금 넣은 회원이 잘 들어갔는지 SELECT로 확인하세요. 힌트: WHERE name = '...'

문제 3

도서 '소나기'의 소장 부수(total_copies)를 1 증가시키세요. (UPDATE) 힌트: SET total_copies = total_copies + 1 WHERE title = '소나기'

문제 4

loan_id가 6인 대출을 반납 처리하세요. (return_date를 오늘로 UPDATE) 힌트: SET return_date = '2026-07-24' WHERE loan_id = 6

문제 5

문제 1에서 넣은 본인 회원을 다시 DELETE로 삭제하세요. 힌트: DELETE FROM member WHERE name = '...'

제출
