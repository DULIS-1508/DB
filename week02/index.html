Week 02 · SELECT 기본과 열 선택

필요한 열만, 중복 없이, 원하는 만큼 조회하기

HOME 실습 가이드 환경·제출 안내 도서관 DB 내려받기

학습 목표

  • 특정 열만 골라서 조회할 수 있다.
  • DISTINCT로 중복을 없애고, AS로 별칭을 붙일 수 있다.
  • LIMIT으로 결과 개수를 제한할 수 있다.

준비

실습 안내를 참고해 도서관 DB를 불러온 뒤 시작하세요. 표 구조가 기억나지 않으면 실습 가이드의 "우리가 쓸 표 3개"를 참고하세요.

실습 과제

아래 문제를 풉니다. week02/answer.sql 파일에 문제 번호와 함께 SQL을 작성하고, 실행 결과를 캡처해 제출하세요.

문제 1

book 테이블의 모든 열, 모든 행을 조회하세요. 힌트: SELECT *

문제 2

book에서 제목(title), 저자(author), 출판연도(pub_year) 세 열만 조회하세요. 힌트: 필요한 열만 콤마로 나열

문제 3

member에 등장하는 학과(dept)를 중복 없이 조회하세요. 힌트: DISTINCT

문제 4

book의 카테고리(category)를 중복 없이 조회하세요. 힌트: DISTINCT

문제 5

book에서 title을 도서명, pub_year를 출판연도라는 별칭으로 바꾸고, 앞에서 10건만 조회하세요. 힌트: AS 별칭 + LIMIT

제출

week02/answer.sql에 답을 작성 → 결과 캡처(result.png) 첨부 → Commit & Push. 자세한 방법은 환경·제출 안내를 참고하세요.
