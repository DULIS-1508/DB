# Week 02 · 2장 데이터 CRUD (생성·조회·수정·삭제)
> 데이터를 넣고(Create) 꺼내고(Read) 고치고(Update) 지우기(Delete)

## 학습 목표
- INSERT로 새 데이터를 넣을 수 있다.
- UPDATE·DELETE로 데이터를 수정·삭제할 수 있다.
- WHERE로 대상을 정확히 지정할 수 있다.
