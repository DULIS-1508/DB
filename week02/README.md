# Week 02 · SELECT 기본과 열 선택
> 필요한 열만, 중복 없이, 원하는 만큼 조회하기

## 학습 목표
- 특정 열만 골라서 조회할 수 있다.
- DISTINCT로 중복을 없애고, AS로 별칭을 붙일 수 있다.
- LIMIT으로 결과 개수를 제한할 수 있다.

## 준비
[실습 안내](../guide.html)를 참고해 `db/library_schema.sql`을 불러온 뒤 시작하세요.

## 실습 과제
1. book 테이블의 모든 열, 모든 행을 조회하세요. (힌트: SELECT *)
2. book에서 제목(title), 저자(author), 출판연도(pub_year) 세 열만 조회하세요. (힌트: 필요한 열만 콤마로 나열)
3. member에 등장하는 학과(dept)를 중복 없이 조회하세요. (힌트: DISTINCT)
4. book의 카테고리(category)를 중복 없이 조회하세요. (힌트: DISTINCT)
5. book에서 title을 도서명, pub_year를 출판연도라는 별칭으로 바꾸고, 앞에서 10건만 조회하세요. (힌트: AS 별칭 + LIMIT)

## 제출 방법
1. `answer.sql`에 문제 번호와 함께 SQL을 작성합니다.
2. 실행 결과를 캡처해 `result.png`로 이 폴더에 함께 올립니다.
3. **Commit & Push** 하면 제출 완료입니다.
