Week 05 · 다양한 자료형 활용

5장 · 숫자·문자·날짜형 데이터를 조건으로 다루기

HOME 웹에서 SQL 연습 실습 가이드 환경·제출 안내 도서관 DB 내려받기

학습 목표

  • 문자열을 LIKE로 부분 검색할 수 있다.
  • 날짜를 BETWEEN·MONTH() 등으로 다룰 수 있다.
  • IS NULL로 빈 값을 구분할 수 있다.

준비

웹에서 SQL 연습에서 도서관 DB를 골라 바로 실습할 수 있습니다. 표 구조는 실습 가이드를 참고하세요.

날짜 함수(YEAR·MONTH·DAY)는 연습창에서도 동작합니다.

실습 과제

아래 문제를 풀어 week05/answer.sql에 문제 번호와 함께 SQL을 작성하고, 실행 결과를 캡처해 제출하세요.

문제 1

2024년에 가입한 회원을 조회하세요. 힌트: join_date BETWEEN '2024-01-01' AND '2024-12-31'

문제 2

대출일이 3월인 대출 기록을 조회하세요. 힌트: MONTH(loan_date) = 3

문제 3

제목이 '데'로 시작하는 도서를 조회하세요. 힌트: LIKE '데%'

문제 4

현재 연체 중인 대출을 조회하세요. (미반납 + 반납예정일이 오늘 이전) 힌트: return_date IS NULL AND due_date < '2026-07-23'

문제 5

이메일이 'minjun'으로 시작하는 회원을 조회하세요. 힌트: LIKE 'minjun%'
