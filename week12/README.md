# Week 12 · 실습·발표 ① 사서의 눈으로 데이터 분석하기
> 배운 SQL로 '도서관이 실제로 답해야 할 질문'에 데이터로 답합니다

## 학습 목표
- 실무 질문을 SQL 분석으로 바꿔 답할 수 있다.
- 분석 결과를 의사결정·개선안으로 연결할 수 있다.
- 데이터가 현장(도서관 운영)에 어떻게 쓰이는지 체감한다.

## 과제
- 아래 ‘사서의 질문’ 중 3개 이상을 SQL로 분석하고, 결과를 캡처하세요.
- ① 어떤 분야 책을 더 사야 할까? — 카테고리별 대출 건수 순위② 인기 없는 책은? — 한 번도(또는 거의) 대출되지 않은 도서③ 연체 관리가 필요한가? — 현재 연체 건수·연체가 잦은 도서/회원④ 누가 무엇을 보나? — 학과별로 많이 빌리는 분야⑤ 장서는 충분한가? — 대출이 많은데 소장 부수가 적은 도서
- 각 분석마다 “그래서 사서는 무엇을 하면 좋을까?”를 한 줄 제안으로 답안에 남기세요. (데이터 → 결정: 예 “○○ 분야 예산을 늘리자”, “△△ 책은 서가에서 빼자”)

## 제출
`answer.sql`에 작성 → 결과 캡처(`result.png`) 첨부 → Commit & Push.
