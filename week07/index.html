Week 07 · 조인 (2) 외부 조인과 NULL

한쪽에만 있는 데이터까지 놓치지 않기 (LEFT JOIN)

HOME 실습 가이드 환경·제출 안내 도서관 DB 내려받기

학습 목표

  • LEFT JOIN으로 기준 표의 모든 행을 남길 수 있다.
  • IS NULL로 '연결되지 않은' 행을 찾을 수 있다.
  • 외부 조인과 그룹화를 함께 사용할 수 있다.

준비

실습 안내를 참고해 도서관 DB를 불러온 뒤 시작하세요. 표 구조가 기억나지 않으면 실습 가이드의 "우리가 쓸 표 3개"를 참고하세요.

실습 과제

아래 문제를 풉니다. week07/answer.sql 파일에 문제 번호와 함께 SQL을 작성하고, 실행 결과를 캡처해 제출하세요.

문제 1

모든 회원과 각자의 대출 건수를 구하세요. (한 번도 안 빌린 회원은 0으로) 힌트: member LEFT JOIN loan, GROUP BY, COUNT(loan_id)

문제 2

한 번도 대출된 적이 없는 도서의 제목을 조회하세요. 힌트: book LEFT JOIN loan, WHERE l.loan_id IS NULL

문제 3

한 번도 책을 빌리지 않은 회원의 이름을 조회하세요. 힌트: member LEFT JOIN loan, WHERE l.loan_id IS NULL

문제 4

각 도서의 대출 횟수를 구하고(대출 0회 포함), 많이 빌린 순으로 조회하세요. 힌트: book LEFT JOIN loan, GROUP BY, ORDER BY COUNT DESC

문제 5

현재 대출 중(미반납)인 도서의 제목과 빌린 회원 이름을 조회하세요. 힌트: 조인 후 WHERE l.return_date IS NULL
