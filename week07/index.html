Week 07 · 테이블 조인

7장 · 여러 표를 연결해서 함께 보기 (INNER · LEFT JOIN)

HOME 웹에서 SQL 연습 실습 가이드 환경·제출 안내 정답 확인 도서관 DB 내려받기

학습 목표

  • JOIN ... ON으로 두세 표를 연결할 수 있다.
  • LEFT JOIN으로 한쪽에만 있는 행도 남길 수 있다.
  • 조인 결과에 조건·집계를 적용할 수 있다.

준비

웹에서 SQL 연습에서 도서관 DB를 골라 바로 실습할 수 있습니다. 표 구조는 실습 가이드를 참고하세요.

실습 과제

아래 문제를 풀어 week07/answer.sql에 문제 번호와 함께 SQL을 작성하고, 실행 결과를 캡처해 제출하세요.

문제 1

대출 기록에 회원 이름과 도서 제목을 붙여, 이름·제목·대출일을 조회하세요. 힌트: loan JOIN member JOIN book

문제 2

'김민준'이 빌린 도서 제목을 모두 조회하세요. 힌트: 조인 후 WHERE m.name = '김민준'

문제 3

모든 회원과 각자의 대출 건수를 구하세요. (안 빌린 회원은 0) 힌트: member LEFT JOIN loan, COUNT(l.loan_id)

문제 4

한 번도 대출되지 않은 도서 제목을 조회하세요. 힌트: book LEFT JOIN loan, WHERE l.loan_id IS NULL

문제 5

현재 대출 중(미반납)인 도서 제목과 빌린 회원 이름을 조회하세요. 힌트: 조인 후 WHERE l.return_date IS NULL
