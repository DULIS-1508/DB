1. 실습 환경 준비

🖥️ 가장 쉬운 방법: 아무것도 설치하지 말고 웹에서 SQL 연습 페이지로 가세요. 도서관 데이터가 이미 들어 있어, 코드를 입력하면 같은 화면에서 바로 결과가 나옵니다. 연습은 여기서 하고, 아래 방법들은 과제 제출·후반부 실습에 쓰면 됩니다.

그 밖에 MySQL을 쓰는 방법은 두 가지입니다. 수업 초반에는 (A) 무설치 방식으로 가볍게 시작하고, 테이블을 직접 만드는 후반부에는 (B) 로컬 설치로 넘어갑니다.

(A) 브라우저에서 바로 실습 — 설치 불필요 (초반 권장)

  1. DB Fiddle 접속 → 왼쪽 위 Database를 MySQL 8.0으로 선택
  2. library_schema.sql을 열어, 맨 위 CREATE DATABASE/USE 두 줄을 뺀 나머지를 왼쪽 Schema SQL 칸에 붙여넣기
  3. 오른쪽 Query SQL 칸에 과제 쿼리를 작성하고 Run
그 밖에 OneCompiler, SQL Online 같은 도구도 사용할 수 있습니다.

(B) 내 컴퓨터에 설치 — 후반부(테이블 설계) 권장

  1. MySQL Community Server + MySQL Workbench 설치
  2. Workbench 접속 후, File > Open SQL Script로 library_schema.sql을 열고 실행(⚡)
  3. 왼쪽 Schemas에 library 데이터베이스가 생기면 성공

2. 도서관 DB 불러오기 확인

불러온 뒤 아래 쿼리로 데이터가 잘 들어왔는지 확인하세요.

SELECT COUNT(*) FROM member;  -- 15
SELECT COUNT(*) FROM book;    -- 30
SELECT COUNT(*) FROM loan;    -- 42

3. 과제 제출 방법 (GitHub Classroom)

  1. 교수님이 공지한 GitHub Classroom 초대 링크를 클릭하면, 본인 전용 과제 저장소가 자동으로 생성됩니다.
  2. 해당 주차 폴더(예: week01/) 안의 answer.sql 파일에 작성한 SQL을 채워 넣습니다.
  3. 실행 결과를 캡처해 같은 폴더에 result.png(또는 .jpg)로 함께 올립니다.
  4. 변경 사항을 Commit & Push 하면 제출 완료입니다. (웹에서 파일을 직접 수정·업로드해도 됩니다.)
제출 체크리스트
☑ answer.sql에 각 문제 번호와 쿼리를 함께 작성했는가
☑ 쿼리가 오류 없이 실행되는가
☑ 결과 캡처를 첨부했는가
