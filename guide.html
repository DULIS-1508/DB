1. 실습 환경 준비

🖥️ 가장 쉬운 방법: 아무것도 설치하지 말고 웹에서 SQL 연습 페이지로 가세요. 도서관 데이터가 이미 들어 있어, 코드를 입력하면 같은 화면에서 바로 결과가 나옵니다. 연습은 여기서 하고, 아래 방법들은 과제 제출·후반부 실습에 쓰면 됩니다.

그 밖에 MySQL을 쓰는 방법은 두 가지입니다. 수업 초반에는 (A) 무설치 방식으로 가볍게 시작하고, 테이블을 직접 만드는 후반부에는 (B) 로컬 설치로 넘어갑니다.

(A) 브라우저에서 바로 실습 — 설치 불필요 (초반 권장)

  1. DB Fiddle 접속 → 왼쪽 위 Database를 MySQL 8.0으로 선택
  2. library_schema.sql을 열어, 맨 위 CREATE DATABASE/USE 두 줄을 뺀 나머지를 왼쪽 Schema SQL 칸에 붙여넣기
  3. 오른쪽 Query SQL 칸에 과제 쿼리를 작성하고 Run
그 밖에 OneCompiler, SQL Online 같은 도구도 사용할 수 있습니다.

(B) 내 컴퓨터에 설치 — 후반부(테이블 설계) 권장

  1. MySQL Community Server + MySQL Workbench 설치
  2. Workbench 접속 후, File > Open SQL Script로 library_schema.sql을 열고 실행(⚡)
  3. 왼쪽 Schemas에 library 데이터베이스가 생기면 성공

2. 도서관 DB 불러오기 확인

불러온 뒤 아래 쿼리로 데이터가 잘 들어왔는지 확인하세요.

SELECT COUNT(*) FROM member;  -- 15
SELECT COUNT(*) FROM book;    -- 30
SELECT COUNT(*) FROM loan;    -- 42

3. 과제 제출 방법 (GitHub, 처음이어도 괜찮아요)

😀 겁먹지 마세요. 프로그램 설치도, 어려운 명령어도 필요 없습니다. 인터넷 브라우저(크롬 등)만 있으면 됩니다. 아래 순서대로 클릭만 하면 제출 끝!

준비 — GitHub 계정 만들기 (딱 한 번)

  1. github.com/signup에 접속해 이메일·비밀번호·아이디(username)를 입력하고 가입합니다. (무료)
  2. 가입한 이메일로 온 인증 메일의 확인 버튼을 누르면 준비 끝입니다.

과제 제출 — 매주 이렇게

  1. 초대 링크 열기 — 교수님이 공지한 과제 초대 링크를 클릭합니다.
    처음 한 번은 "Authorize"(권한 허용)와 본인 이름 선택 화면이 나올 수 있어요. 안내대로 눌러 주세요.
  2. 과제 받기 — “Accept this assignment”(과제 수락) 초록 버튼을 누르고 잠깐(10~30초) 기다리면, 나만의 과제 저장소가 자동으로 만들어집니다. 새로 생긴 저장소 주소를 클릭해 들어갑니다.
  3. 답 파일 열기 — 저장소에서 이번 주 폴더(예: week03)를 누르고, 그 안의 answer.sql 파일을 클릭합니다.
  4. 답 작성하기 — 파일 화면 오른쪽 위의 연필 아이콘(✏️ Edit)을 누르면 편집 화면이 열립니다. 여기에 작성한 SQL을 붙여넣거나 입력합니다. 
    -- 문제 1.
SELECT title, author FROM book WHERE category = '컴퓨터';
  5. 저장(제출)하기 — 오른쪽 위 초록색 “Commit changes…” 버튼을 누르고, 다음 창에서 다시 “Commit changes”를 누르면 제출 완료! 🎉
  6. 결과 캡처 올리기 — 웹 연습창에서 실행한 결과 화면을 캡처한 뒤, 저장소 폴더에서 “Add file → Upload files”로 result.png를 올리고 다시 Commit 합니다.
🔁 마감 전이면 몇 번이든 다시 고칠 수 있어요. 답을 수정하고 다시 “Commit changes”를 누르면 가장 최근 내용으로 갱신됩니다. 틀릴까 봐 걱정하지 말고 편하게 제출하세요.
제출 체크리스트
☑ answer.sql에 문제 번호와 SQL을 함께 적었는가
☑ SQL이 오류 없이 실행되는가 (웹 연습창에서 미리 확인)
☑ 결과 캡처(result.png)를 올렸는가
☑ 마지막에 “Commit changes”를 눌렀는가

※ 과제 초대 링크는 수강신청이 확정된 뒤 교수님이 공지합니다. 그때 위 순서대로 진행하면 됩니다.
