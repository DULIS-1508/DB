# Week 09 · 8장 그룹화 분석
> 묶어서 집계하고(GROUP BY), 묶은 결과에 조건 걸기(HAVING)

## 학습 목표
- GROUP BY로 그룹별 집계를 할 수 있다.
- HAVING으로 그룹에 조건을 걸 수 있다.
- 집계 결과를 정렬·제한할 수 있다.

## 실습 과제
1. 카테고리별 도서 수를 구하세요.
2. 출판사별 도서 수를 많은 순으로 조회하세요.
3. 회원 유형별 인원 수를 구하세요.
4. 도서가 4권 이상인 카테고리만 조회하세요.
5. 회원별 대출 건수를 많은 순으로 상위 5명 조회하세요.
