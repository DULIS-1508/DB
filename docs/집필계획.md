# 도서관 데이터로 배우는 데이터베이스 개론 — 집필 마스터 플랜

> **한 줄 콘셉트**: 국내 MySQL 기반 데이터베이스 개론서의 **개념 뼈대는 그대로**,
> 모든 예제·실습 데이터를 **하나의 도서관 데이터베이스**로 통일한 학부 전공 교재.

- **버전**: v0.1 (초안)
- **관통 도메인**: 추상형(유형 혼합) 도서관 모델 — 특정 관종에 종속되지 않는 일반 도서관 DB
- **주 독자·수준**: 문헌정보학/데이터 관련 **학부 전공생**, 1학기(14주) 강의용
- **선수 지식**: 없음(프로그래밍 무경험자도 따라올 수 있게), MySQL/MariaDB 실습

---

## 1. 기획 의도와 차별점

### 1.1 문제의식
국내 데이터베이스 개론서 대부분은 `사원-부서`, `학생-수강`, `쇼핑몰-주문` 같은
예제로 개념을 설명한다. 개념 전달에는 문제가 없지만, 문헌정보학 전공생에게는
**도메인이 낯설어 개념과 실무의 연결이 끊긴다.**

### 1.2 이 책의 해법
- 책 전체를 관통하는 **단 하나의 도서관 데이터베이스**를 설계하고, 1장부터 마지막
  장까지 **같은 스키마·같은 데이터**를 점진적으로 확장하며 모든 개념을 설명한다.
- 학생은 "회원이 책을 빌리고 반납하고 연체료를 내는" 익숙한 흐름 위에서
  키·조인·정규화·트랜잭션·트리거를 **자연스럽게** 익힌다.
- 표준(ISBN, KDC/DDC 분류, 청구기호, MARC 개념)과 연결해 **전공 심화로 확장**한다.

### 1.3 설계 원칙
1. **누적성**: 각 장의 스키마·데이터는 앞 장을 이어받아 확장한다(버리고 새로 만들지 않음).
2. **개념 → 도서관 매핑 → 실습 → 과제**의 4단 구성을 모든 장에서 반복한다.
3. **추상형 유지**: 실제 특정 도서관을 모사하지 않되, 현실 규칙(대출기간·연체·예약)은 반영한다.
4. **재현 가능성**: 모든 예제는 제공 SQL 스크립트로 누구나 동일하게 재현할 수 있다.

## 2. 관통 도메인 — 추상형 도서관 데이터 모델

교재 전체가 사용하는 핵심 엔터티(초안). 초반 장에서는 일부만 등장하고,
정규화·트랜잭션 장을 거치며 완성형으로 확장된다.

| 엔터티 | 의미 | 핵심 속성(예) |
|---|---|---|
| **자료(book)** | 서지 단위(제목 레벨) | ISBN, 서명, 출판사, 출판년도, KDC분류 |
| **저자(author)** | 저자/역자 | 이름, 국적 |
| **자료저자(book_author)** | 자료:저자 N:M 연결 | book_id, author_id, 역할(저자/역자/편저) |
| **출판사(publisher)** | 발행처 | 이름, 소재지 |
| **소장본(copy)** | 물리적 개별 자료(등록번호 단위) | 청구기호, 등록번호, 상태, 소장분관 |
| **회원(member)** | 이용자 | 이름, 유형(학생/교직원/일반), 가입일, 상태 |
| **대출(loan)** | 대출 트랜잭션 | copy_id, member_id, 대출일, 반납예정일, 반납일 |
| **예약(reservation)** | 대출중 자료 예약 | book_id, member_id, 예약일, 상태 |
| **연체료(fine)** | 연체·분실 부과금 | loan_id, 금액, 부과일, 납부일 |
| **분관(branch)** | 도서관/분관 | 이름, 위치 |
| **분류(kdc_class)** | 한국십진분류(참조) | 분류코드, 분류명 |

### 개념 ERD (텍스트 스케치)
```
publisher 1───N book N───M author        (book_author)
                 │
                 │ 1
                 ▼ N
                copy ───────N loan N─────── member
                 │                            │
                 │ N                          │ 1
                 ▼                            ▼ N
               branch                     reservation
                                             fine (loan 1───N)
```
- 자료(book) : 소장본(copy) = **1:N** (같은 책을 여러 권 소장)
- 소장본(copy) : 대출(loan) = **1:N** (한 권이 시간에 따라 여러 번 대출)
- 회원(member) : 대출(loan) = **1:N**
- 자료(book) : 저자(author) = **N:M** (공저·역자)

## 3. 전체 목차 — 14주 / 14장 구성

> 각 장은 **[개론서 개념] → [도서관 데이터 매핑] → [MySQL 실습] → [과제]** 순서.
> 저장소의 `week01`~`week14` 과제 슬롯과 1:1 대응.

### 1부. 데이터베이스의 기초

**1장 (1주) — 데이터베이스와 도서관 정보시스템**
- 개념: 데이터/정보, 파일시스템의 한계, DBMS의 역할, 데이터베이스의 특징
- 매핑: 수기 대출카드 → 통합도서관시스템(ILS)으로의 전환 스토리
- 실습: MySQL/MariaDB·클라이언트 도구 설치, 서버 접속, `SHOW DATABASES`
- 과제: 우리 학교/동네 도서관에서 관리할 데이터 항목 브레인스토밍

**2장 (2주) — 관계형 데이터 모델과 키**
- 개념: 릴레이션·속성·튜플·도메인, 기본키/후보키/외래키/대체키, 무결성 규칙
- 매핑: 도서관 핵심 엔터티(자료·회원·대출) 식별, 각 엔터티의 키 설계
- 실습: 표(릴레이션)로 도서관 데이터 표현, 키 후보 찾기 워크시트
- 과제: 소장본과 자료의 차이를 키 관점에서 설명

**3장 (3주) — 데이터 모델링과 ERD**
- 개념: 개체-관계 모델, 카디널리티(1:1/1:N/N:M), 약한 개체, 식별/비식별 관계
- 매핑: 도서관 개념 ERD 설계(자료·소장본·회원·대출·저자·출판사)
- 실습: ERD 작도(도구 자유), N:M(자료-저자) 해소
- 과제: 예약·연체료까지 포함한 확장 ERD 그리기

### 2부. SQL로 다루는 도서관 데이터

**4장 (4주) — MySQL 환경과 DDL(데이터 정의)**
- 개념: 데이터 정의어, 자료형, 제약조건(PK/FK/NOT NULL/UNIQUE/CHECK/DEFAULT), AUTO_INCREMENT
- 매핑: 3장 ERD를 실제 `CREATE TABLE`로 구현 — **도서관 스키마 v1 확정**
- 실습: `CREATE DATABASE library`, 전체 테이블 생성, `DESC`/`SHOW CREATE TABLE`
- 과제: 청구기호·ISBN에 적절한 자료형·제약조건 부여

**5장 (5주) — 데이터 입력·수정·삭제(DML)**
- 개념: `INSERT`/`UPDATE`/`DELETE`, 다중행 삽입, 외래키 위반, 트랜잭션 미리보기
- 매핑: 샘플 도서관 데이터 적재(자료 50·회원 30·대출 100건 규모)
- 실습: 제공 `seed.sql`로 데이터 적재, 반납 처리(UPDATE)
- 과제: 신규 회원 가입·자료 등록·대출 발생 시나리오 작성

**6장 (6주) — 기본 조회 SELECT**
- 개념: `SELECT`, `WHERE`, 비교·논리 연산자, `LIKE`/패턴, `ORDER BY`, `LIMIT`, `DISTINCT`
- 매핑: 도서 검색(서명·저자·출판년도), 대출가능 자료 찾기
- 실습: "2020년 이후 출판된 소설", "제목에 '데이터' 포함 도서"
- 과제: 검색 시나리오 10개를 SQL로 작성

**7장 (7주) — 함수와 집계**
- 개념: 문자/숫자/날짜 함수, `GROUP BY`, `HAVING`, 집계함수(COUNT/SUM/AVG/MAX/MIN)
- 매핑: 월별 대출 통계, 분류(KDC)별 장서 수, 회원 유형별 대출량
- 실습: `DATEDIFF`로 대출기간 계산, 인기 분류 TOP 5
- 과제: 도서관 월간 통계 리포트 쿼리 세트
- **※ 중간고사 범위(1~7장)**

### 3부. 관계로 엮고 설계를 다듬기

**8장 (8주) — 조인(JOIN)**
- 개념: `INNER`/`LEFT`/`RIGHT`/`SELF` JOIN, 다중 테이블 조인, 조인 조건
- 매핑: 대출↔회원↔소장본↔자료 4중 조인, 한 번도 대출되지 않은 자료(LEFT JOIN)
- 실습: "현재 대출중인 자료와 대출 회원 목록", "저자별 소장 자료 목록"
- 과제: 연체 중인 회원과 자료를 한 눈에 보는 조인 쿼리

**9장 (9주) — 서브쿼리와 집합 연산**
- 개념: 단일행/다중행 서브쿼리, 상관 서브쿼리, `IN`/`EXISTS`/`ANY`/`ALL`, `UNION`
- 매핑: "평균보다 많이 대출한 회원", "한 번도 대출 안 된 자료", "예약 대기 자료"
- 실습: 상관 서브쿼리로 회원별 최근 대출 찾기
- 과제: 서브쿼리 vs 조인으로 같은 문제 두 가지 방법 풀이

**10장 (10주) — 정규화와 스키마 개선**
- 개념: 이상현상(삽입/삭제/갱신), 함수적 종속, 1NF·2NF·3NF, 반정규화 개요
- 매핑: 저자 반복·출판사 중복이 있는 "나쁜 설계"를 단계적으로 정규화 → **스키마 v2**
- 실습: 비정규 테이블에서 이상현상 재현 후 분해
- 과제: 제공된 평면 테이블을 3NF로 정규화

**11장 (11주) — 뷰와 인덱스**
- 개념: 뷰 생성·활용·갱신 제약, 인덱스 구조(B-Tree 개요), `EXPLAIN`, 성능
- 매핑: `v_대출가능도서` 뷰, ISBN·서명 인덱스로 검색 성능 비교
- 실습: 인덱스 유무에 따른 `EXPLAIN` 비교
- 과제: 자주 쓰는 조회를 뷰로 캡슐화

### 4부. 무결성·자동화·응용

**12장 (12주) — 트랜잭션과 무결성**
- 개념: 트랜잭션·ACID, `COMMIT`/`ROLLBACK`/`SAVEPOINT`, 격리수준, 락, 동시성 문제
- 매핑: 대출 처리(소장본 상태 변경 + 대출행 삽입)를 하나의 트랜잭션으로
- 실습: 반납·연체료 부과를 원자적으로 처리, 실패 시 롤백
- 과제: 동시 예약 충돌 시나리오 분석

**13장 (13주) — 저장 프로그램(프로시저·함수·트리거·이벤트)**
- 개념: 저장 프로시저·저장 함수, 트리거, 이벤트 스케줄러, 흐름 제어
- 매핑: 반납 시 연체료 자동 계산 트리거, 반납 시 예약 자동 전환 프로시저
- 실습: `대출처리()` 프로시저, `AFTER UPDATE` 연체료 트리거
- 과제: 회원 등급별 대출권수 제한을 프로시저로 구현

**14장 (14주) — 응용 연동과 종합 프로젝트**
- 개념: 애플리케이션-DB 연동 개요(Python/PHP), SQL 인젝션과 방어, 백업/복구, 권한
- 매핑: 간단한 도서 검색·대출 화면과 DB 연결(개요 수준)
- 실습: Python으로 도서관 DB 조회 스크립트, `mysqldump` 백업
- 과제(팀 프로젝트): 특정 관종 요구를 반영한 도서관 DB 설계·구현·발표
- **※ 기말: 프로젝트 발표 및 기말고사(8~14장)**
