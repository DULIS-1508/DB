1. 데이터베이스가 뭔가요?

어렵게 생각하지 마세요. 데이터베이스(DB)는 "여러 개의 표(엑셀 시트)를 잘 정리해 모아 둔 것"입니다. 우리는 도서관을 예로 들어 공부합니다.

📒 도서관 대장(종이)

회원 명부, 도서 목록, 대출 기록을 각각 노트에 적어 둔 것

📊 엑셀 파일

그 노트들을 시트로 옮긴 것 (시트 하나 = 표 하나)

🗄️ 데이터베이스

그 표들을 컴퓨터가 빠르게 찾고 계산할 수 있게 담아 둔 것

이 수업에서는 MySQL이라는 데이터베이스를 사용합니다.

3. SQL은 "표에게 던지는 질문"

표에서 원하는 정보를 꺼내려면 SQL이라는 언어로 질문합니다. 가장 기본은 SELECT 문장이에요. 딱 이 구조만 기억하세요.

SELECT 보고 싶은 열
FROM   어느 표에서
WHERE  조건 (선택 사항);

예를 들어 "회원 표에서 이름과 학과를 보여줘"는 이렇게 씁니다.

SELECT name, dept
FROM   member;
✅ 문장 끝에는 꼭 세미콜론 ; 을 붙이세요.
✅ 대소문자는 상관없지만, 열·표 이름은 철자를 정확히 써야 해요.

4. 5분 만에 첫 쿼리 실행하기 (설치 없이)

  1. db-fiddle.com 에 접속합니다.
  2. 왼쪽 위 Database를 MySQL 8.0으로 선택합니다.
  3. library_schema.sql을 열어 내용을 복사한 뒤, 맨 위 CREATE DATABASE·USE 두 줄만 빼고 왼쪽 Schema SQL 칸에 붙여넣습니다. (도서관 표를 만드는 부분)
  4. 오른쪽 Query SQL 칸에 아래를 그대로 입력합니다. 
    SELECT name, dept
FROM   member;
  5. 가운데 Run 버튼을 누릅니다. 아래에 회원 이름과 학과가 표로 나오면 성공! 🎉
직접 설치해서 하고 싶다면 환경·제출 안내에서 MySQL Workbench 설치 방법을 확인하세요. (수업 후반 테이블 만들기 실습에 필요)

6. 자주 나오는 오류와 해결

이런 메시지가 나오면이유해결
You have an error ... near ... 문법(오타·세미콜론) 철자와 콤마·세미콜론을 확인하세요.
Table 'member' doesn't exist 표를 아직 안 만듦 왼쪽 Schema SQL에 스키마를 먼저 붙여넣고 Run 하세요.
Unknown column 'nmae' 열 이름 오타 정확한 이름(name 등)으로 고치세요.
결과가 0건 조건이 너무 좁음 WHERE 조건을 다시 확인하세요.
오류 메시지는 겁먹을 필요 없어요. 대부분 오타 한 글자입니다. 메시지의 near 뒤에 적힌 부분 근처를 살펴보세요.

7. 기본 SQL 치트시트

하고 싶은 것이렇게 쓰세요
표 전체 보기SELECT * FROM book;
특정 열만 보기SELECT title, author FROM book;
조건으로 걸러 보기SELECT * FROM book WHERE category = '문학';
정렬해서 보기SELECT * FROM book ORDER BY pub_year DESC;
개수 세기SELECT COUNT(*) FROM member;
중복 없이 보기SELECT DISTINCT publisher FROM book;
몇 개만 보기SELECT * FROM book LIMIT 5;

8. 막히면?

Q. 스키마를 붙여넣었는데 표가 안 보여요.

A. Schema SQL 칸에 붙여넣은 뒤 Run(또는 화면 새로고침 후 다시 실행)을 했는지 확인하세요.

Q. 한글이 깨져요.

A. 스키마 맨 위 문자셋(utf8mb4) 부분까지 함께 붙여넣었는지 확인하세요.

Q. 어디까지가 과제인가요?

A. 홈에서 해당 주차 과제 페이지를 열면 문제와 제출 방법이 있습니다.

그래도 막히면 수업 게시판이나 이메일로 교수님께 질문하세요. 오류 메시지를 함께 캡처해 보내면 빠르게 도와드릴 수 있어요.
