실습·발표 ② · 스스로 '데이터로 개선할 것'을 찾아 분석하고, 현장에 접목할 아이디어를 냅니다

HOME 웹에서 SQL 연습 실습 가이드 환경·제출 안내 정답 확인 도서관 DB 내려받기

이 실습의 목적

이 수업의 핵심입니다 — 배운 기술을 ‘그래서 어디에 쓸까’로 연결하는 연습입니다. 도서관이 아니어도 좋아요(서점·기록관·박물관·동아리 회비 등 관심 있는 데이터 현장이면 됩니다).
  • 데이터로 풀 문제·아이디어를 스스로 발굴한다.
  • 아이디어를 SQL 분석으로 검증한다.
  • 분석 결과를 현장 적용안으로 구체화한다.

실습 과제

아래 내용을 수행하고 결과를 week13/answer.sql(또는 발표자료)로 제출하세요.
  • 1단계 — 아이디어 정하기: 데이터로 개선하고 싶은 것 1가지를 정하세요. (예: “대출 데이터로 개인 맞춤 도서 추천을 해보자”, “연체 예측으로 미리 알림을 보내자”)
  • 2단계 — 분석하기: 아이디어를 확인할 질문 2~3개를 만들고 SQL로 답하세요. (질문 → SQL → 결과)
  • 3단계 — 현장 접목 제안: 결과를 바탕으로 “실제 현장에 어떻게 적용할지”를 3~5줄로 제안하세요.

제출

week13/answer.sql에 답을 작성 → 결과 캡처(result.png) 첨부 → Commit & Push. 자세한 방법은 환경·제출 안내를 참고하세요.
