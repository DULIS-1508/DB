# Week 13 · 실습·발표 ② 미니 프로젝트 — 나의 데이터 활용 아이디어
> 스스로 '데이터로 개선할 것'을 찾아 분석하고, 현장에 접목할 아이디어를 냅니다

## 학습 목표
- 데이터로 풀 문제·아이디어를 스스로 발굴한다.
- 아이디어를 SQL 분석으로 검증한다.
- 분석 결과를 현장 적용안으로 구체화한다.

## 과제
- 1단계 — 아이디어 정하기: 데이터로 개선하고 싶은 것 1가지를 정하세요. (예: “대출 데이터로 개인 맞춤 도서 추천을 해보자”, “연체 예측으로 미리 알림을 보내자”)
- 2단계 — 분석하기: 아이디어를 확인할 질문 2~3개를 만들고 SQL로 답하세요. (질문 → SQL → 결과)
- 3단계 — 현장 접목 제안: 결과를 바탕으로 “실제 현장에 어떻게 적용할지”를 3~5줄로 제안하세요.

## 제출
`answer.sql`에 작성 → 결과 캡처(`result.png`) 첨부 → Commit & Push.
