# Week 13 · 실습·발표 ② 미니 프로젝트 (나만의 질문)

## 학습 목표
- 스스로 분석 질문을 설계한다.
- 질문에 답하는 SQL을 작성하고 결과를 정리한다.

## 과제
- 도서관 데이터로 직접 궁금한 질문 3가지를 만들고, 각각 SQL로 답하세요.
- 예: "어떤 학과가 컴퓨터 분야 책을 가장 많이 빌릴까?" 처럼 자유롭게.
- 질문 → SQL → 결과 → 한 줄 해석 순서로 정리해 제출하세요.

## 제출
`answer.sql`에 작성 → 결과 캡처(`result.png`) 첨부 → Commit & Push.
