# Week 01 · 오리엔테이션과 첫 SELECT

## 학습 목표
- 도서관 데이터베이스를 실습 환경에 불러올 수 있다.
- `SELECT ... FROM ...` 으로 테이블을 조회할 수 있다.
- 필요한 열만 골라서 조회할 수 있다.

## 준비
1. [실습 안내](../guide.html) 또는 저장소의 `guide.html`을 참고해 `db/library_schema.sql`을 불러옵니다.
2. 아래로 데이터가 준비됐는지 확인합니다.
   ```sql
   SELECT COUNT(*) FROM member;  -- 15
   SELECT COUNT(*) FROM book;    -- 30
   SELECT COUNT(*) FROM loan;    -- 42
   ```

## 실습 과제
1. **회원 전체 조회** — `member` 테이블의 모든 열, 모든 행을 조회하세요.
2. **도서 제목과 저자만 조회** — `book` 테이블에서 `title`, `author` 두 열만 조회하세요.
3. **출판사 목록(중복 없이)** — `book`의 `publisher`를 중복 없이 조회하세요. (힌트: `DISTINCT`)
4. **별칭 붙이기** — `member`에서 `name`→`이름`, `dept`→`학과` 별칭으로 조회하세요. (힌트: `AS`)

## 제출 방법
1. `answer.sql`에 문제 번호와 함께 SQL을 작성합니다.
2. 실행 결과를 캡처해 `result.png`(또는 `.jpg`)로 이 폴더에 함께 올립니다.
3. **Commit & Push** 하면 제출 완료입니다.
