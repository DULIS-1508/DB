HOME 실습 가이드 환경·제출 안내 정답 확인 도서관 DB 내려받기

학습 목표

  • 도서관 데이터베이스를 실습 환경에 불러올 수 있다.
  • SELECT ... FROM ... 구문으로 테이블 전체를 조회할 수 있다.
  • 필요한 열만 선택해서 조회할 수 있다.

준비

실습 안내를 참고해 library_schema.sql을 불러온 뒤, 아래 쿼리로 데이터가 준비됐는지 확인하세요.

SELECT COUNT(*) FROM member;  -- 15 이면 정상

실습 과제

아래 4문제를 풉니다. week01/answer.sql 파일에 문제 번호와 함께 SQL을 작성하고, 실행 결과를 캡처해 제출하세요.

문제 1. 회원 전체 조회

member 테이블의 모든 열, 모든 행을 조회하세요.

문제 2. 도서 제목과 저자만 조회

book 테이블에서 제목(title)과 저자(author) 두 열만 조회하세요.

문제 3. 출판사 목록 (중복 없이)

book 테이블에 등장하는 출판사(publisher)를 중복 없이 조회하세요. 힌트: DISTINCT

문제 4. 회원 이름과 학과에 별칭 붙이기

member 테이블에서 name은 이름, dept는 학과라는 별칭(AS)으로 바꿔 조회하세요. 힌트: AS
